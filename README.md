# 번뜩 (memory-idea)

길을 가다 번뜩 떠오른 생각, 좋다고 느낀 글의 캡처, 영상, 링크를 보내면 **원문 그대로 기록**하고, 내 컴퓨터에 설치된 **Claude CLI 또는 Codex CLI**가 자동으로 아이데이션해 주는 개인용 모바일 웹앱(PWA)입니다.

## 하는 일

1. **보내기**: 텍스트, 사진·캡처, 영상, 음성, 텍스트 파일, 링크를 채팅하듯 보냅니다. 보내는 곳은 세 가지입니다.
   - 웹앱 입력창
   - 안드로이드 "공유" 메뉴 (웹앱을 홈 화면에 설치한 경우)
   - **텔레그램 봇**: 봇에게 보내거나 다른 대화방 메시지를 전달하면 됩니다.
2. **원문 저장**: 입력한 글은 띄어쓰기와 줄바꿈까지 바꾸지 않고, 첨부 파일은 원본 파일 그대로 `data/`에 저장합니다. AI 결과는 원문과 분리해 따로 저장합니다.
3. **링크 따라가 읽기**: 링크가 있으면 페이지 본문을 직접 가져와 AI에게 넘기고, 링크마다 요약, 핵심 내용, 저장한 이유를 정리합니다. 가져온 본문은 기록에 함께 저장되어 나중에 원문 페이지가 사라져도 남습니다.
4. **자동 분류**: 기록마다 분류 하나와 태그를 AI가 붙입니다. 이미 쓰던 분류와 태그를 우선 재사용해서 같은 주제가 여러 이름으로 흩어지지 않게 합니다. 분류는 화면에서 직접 바꿀 수 있고, 직접 바꾼 분류는 다시 아이데이션해도 유지됩니다.
5. **자동 아이데이션**: 저장되면 AI가 원문을 읽고 아래 내용을 만듭니다.
   - 제목, 요약, 분류, 태그, 유형(아이디어, 영감, 문제의식, 질문, 메모, 자료)
   - 원문 해석
   - 구체화: 문제, 대상, 방법, 차별점
   - 서로 다른 발전 방향 3가지
   - 생각해볼 질문, 이번 주에 해볼 작은 행동
   - 예전 기록 중 관련 있는 것과의 연결
6. **이어서 발전시키기**: 기록마다 AI와 대화하며 아이디어를 더 키울 수 있습니다. 텔레그램에서는 정리 결과 메시지에 답장하면 됩니다.
7. **다시 아이데이션**: 엔진을 바꿔 다시 돌릴 수 있고, 이전 결과는 지우지 않고 남겨 둡니다. 본문을 못 가져온 링크는 이때 다시 시도합니다.
8. **찾기와 내보내기**: 검색(링크 본문 포함), 분류와 태그 필터, 전체 기록 마크다운 내보내기(`/api/export.md`)를 지원합니다.

첨부별 처리 방식:

| 보낸 것 | AI에 전달되는 내용 |
| --- | --- |
| 텍스트 | 원문 그대로 |
| 사진, 캡처 | 이미지 파일 자체 (Claude는 Read 도구로, Codex는 `--image`로 읽음) |
| 영상 | ffmpeg가 있으면 앞·중간·끝 대표 프레임 3장, 없으면 파일 정보만 |
| 일반 웹페이지 | 메뉴와 광고를 걷어 낸 본문 (최대 5만 자, EUC-KR 같은 옛 인코딩도 처리) |
| 네이버 블로그 | 모바일 주소로 바꿔 본문을 읽음 |
| 유튜브 | 제목, 채널, 영상 설명. `yt-dlp`를 설치하면 자막(한국어 우선)까지 |
| X(트위터) | 게시물 본문 |
| 로그인이 필요한 곳 (인스타그램, 네이버 카페, 페이스북 등) | 읽지 못함. AI에게 "본문을 가져오지 못함"으로 알려 내용을 지어내지 않게 함 |
| 텍스트 파일 | 파일 내용 |
| 그 밖의 파일 | 파일 이름과 형식만 |

## 구조

```
휴대폰 (PWA) ──HTTP──▶ 내 컴퓨터의 Node 서버 ──▶ claude -p / codex exec
텔레그램 봇 ◀─롱 폴링─┘   ├─ 링크 본문 가져오기
                          └─ data/ideas.json, data/uploads/
```

Claude CLI와 Codex CLI는 내 컴퓨터에 로그인된 계정으로 실행되므로, 서버는 CLI가 설치된 컴퓨터에서 돌려야 합니다. AI 호출은 한 번에 하나씩 대기열로 처리하며, 서버를 껐다 켜도 남은 작업을 이어서 처리합니다.

## 실행

준비물: Node.js 18.17 이상, 그리고 아래 중 하나 이상

- Claude CLI: `npm i -g @anthropic-ai/claude-code` 후 `claude` 실행해 로그인
- Codex CLI: `npm i -g @openai/codex` 후 `codex` 실행해 로그인
- (선택) ffmpeg: 영상에서 프레임을 뽑을 때 사용
- (선택) yt-dlp: 유튜브 자막을 가져올 때 사용

```bash
npm install
npm start            # http://localhost:3939
```

AI 없이 화면과 흐름만 보려면 `npm run mock`, 자동 점검은 `npm test`입니다.

## 휴대폰에서 쓰기

PWA 설치와 공유 메뉴 연동은 **HTTPS** 주소에서만 됩니다. 같은 와이파이에서 `http://컴퓨터IP:3939`로 접속하면 기록과 아이데이션은 되지만 홈 화면 설치와 공유 메뉴는 동작하지 않습니다.

밖에서도 쓰려면 HTTPS 터널을 하나 붙이는 방법이 가장 간단합니다.

- **Tailscale** (추천, 내 기기끼리만 접속): 컴퓨터와 휴대폰에 Tailscale을 설치하고 `tailscale serve --bg 3939` 실행. 표시되는 `https://<컴퓨터이름>.<tailnet>.ts.net` 주소로 접속합니다.
- **Cloudflare Tunnel**: `cloudflared tunnel --url http://localhost:3939`. 공개 주소가 생기므로 반드시 `ACCESS_TOKEN`을 설정하세요.

접속한 뒤 브라우저 메뉴에서 "홈 화면에 추가"를 누르면 앱처럼 쓸 수 있습니다. 안드로이드는 설치 후 사진, 브라우저, 유튜브 등의 공유 메뉴에 "번뜩"이 나타납니다. iOS는 웹앱 공유 대상 기능을 지원하지 않아서, 앱 안에서 첨부 버튼을 쓰거나 글을 붙여 넣어야 합니다.

## 텔레그램 연동

봇이 텔레그램 서버에 새 메시지를 계속 물어보는 방식(롱 폴링)이라 공개 주소나 HTTPS 없이 집 컴퓨터에서 바로 됩니다.

1. 텔레그램에서 `@BotFather`에게 `/newbot`을 보내 봇을 만들고 토큰을 받습니다.
2. `.env.example`을 `.env`로 복사하고 `TELEGRAM_BOT_TOKEN`에 토큰을 넣은 뒤 서버를 시작합니다.
3. 만든 봇에게 아무 말이나 보내면 "내 텔레그램 ID: 123456789"라고 답합니다. 그 숫자를 `.env`의 `TELEGRAM_ALLOWED_USERS`에 넣고 서버를 다시 시작합니다. 여기에 없는 사람이 보낸 메시지는 저장하지 않습니다.
4. 이제 봇에게 보내면 됩니다.
   - 글, 사진, 영상, 음성, 파일, 링크를 보내거나 다른 대화방 메시지를 전달합니다. 사진 여러 장을 한 번에 보내면 기록 하나로 묶입니다.
   - 저장되면 바로 "기록했어요" 답장이 오고, 정리가 끝나면 분류, 링크 정리, 발전 방향, 다음 행동이 담긴 메시지가 옵니다.
   - 그 정리 메시지에 답장하면 그 아이디어를 이어서 발전시키는 대화가 됩니다. 웹앱의 "이어서 발전시키기"에도 같이 남습니다.
   - `/recent`로 최근 기록 5개를 볼 수 있습니다.
5. `PUBLIC_URL`에 웹앱 주소를 넣으면 정리 메시지에 "자세히 보기" 링크가 붙습니다.

텔레그램 봇은 20MB가 넘는 파일을 내려받을 수 없습니다. 큰 영상은 웹앱으로 올려 주세요.

## 설정 (환경 변수)

프로젝트 폴더의 `.env` 파일에 적어 두면 서버가 시작할 때 읽습니다. `.env.example`을 복사해서 쓰세요.

| 변수 | 기본값 | 설명 |
| --- | --- | --- |
| `PORT` | `3939` | 서버 포트 |
| `HOST` | `0.0.0.0` | 내 컴퓨터에서만 쓰려면 `127.0.0.1` |
| `ACCESS_TOKEN` | 없음 | 설정하면 첫 접속 때 이 값을 입력해야 함. 외부에 열 때는 필수 |
| `DATA_DIR` | `./data` | 기록과 첨부 저장 위치 |
| `DEFAULT_ENGINE` | `auto` | `auto`(Claude 먼저, 실패하면 Codex), `claude`, `codex` |
| `CLAUDE_MODEL` | CLI 기본값 | `claude --model`에 넘길 값 |
| `CODEX_MODEL` | CLI 기본값 | `codex exec --model`에 넘길 값 |
| `CLAUDE_BIN`, `CODEX_BIN` | `claude`, `codex` | CLI 실행 파일 경로 |
| `AI_TIMEOUT_MS` | `300000` | AI 한 번 호출의 제한 시간 |
| `MAX_UPLOAD_MB` | `300` | 첨부 파일 하나의 최대 크기 |
| `PUBLIC_URL` | 없음 | 웹앱 주소. 텔레그램 메시지의 "자세히 보기" 링크에 사용 |
| `TELEGRAM_BOT_TOKEN` | 없음 | 설정하면 텔레그램 봇을 켬 |
| `TELEGRAM_ALLOWED_USERS` | 없음 | 기록을 받을 텔레그램 사용자 ID, 쉼표로 구분 |
| `LINK_MAX_CHARS` | `50000` | 링크 하나에서 가져올 본문 최대 글자 수 |
| `MOCK_AI` | 없음 | `1`이면 AI 대신 고정 응답 (테스트용) |

예: `ACCESS_TOKEN=아무도모를문자열 DEFAULT_ENGINE=claude npm start`

화면 오른쪽 위의 선택 상자(자동, Claude, Codex)로 기록마다 엔진을 고를 수도 있습니다.

## AI 호출 방식

- Claude: `claude -p --output-format json --allowedTools Read --add-dir <DATA_DIR>`. 프롬프트는 표준 입력으로 넘기고, 첨부 이미지 경로를 알려 주어 Read 도구로만 열게 합니다.
- Codex: `codex exec --skip-git-repo-check --sandbox read-only --output-last-message <파일> --image=<이미지들> -`. 읽기 전용 샌드박스에서 실행합니다.

프롬프트와 결과 형식은 `lib/ai.js`에 있습니다. 결과 JSON의 항목을 바꾸고 싶으면 `IDEATION_SCHEMA`와 `parseIdeation`, 화면의 `renderIdeation`(`public/app.js`)을 함께 고치면 됩니다.

## 파일 구성

```
server.js            서버, API, 작업 대기열, 공유 받기(/share)
lib/store.js         기록 저장 (data/ideas.json)
lib/ai.js            Claude/Codex CLI 호출, 프롬프트, 결과 파싱
lib/links.js         링크 본문 읽기 (웹페이지, 네이버 블로그, 유튜브, X)
lib/media.js         영상 프레임 추출
lib/telegram.js      텔레그램 봇
lib/env.js           .env 읽기
public/              PWA 화면 (index.html, app.js, style.css, manifest, sw.js)
scripts/smoke-test.js  MOCK 모드 전체 흐름 점검 (가짜 웹사이트, 가짜 텔레그램 API 포함)
```

## 데이터 백업

모든 기록은 `data/` 폴더 하나에 있습니다. 이 폴더를 복사해 두면 백업이 끝나고, 사람이 읽기 좋은 형태가 필요하면 화면 오른쪽 위 내려받기 버튼으로 마크다운 파일을 받을 수 있습니다.

## 카카오톡은?

카카오톡은 개인 대화방을 프로그램이 읽는 공식 방법이 없어서, 텔레그램처럼 "내 계정으로 봇에게 보내기"는 할 수 없습니다. 방법은 두 가지입니다.

- **지금 바로 되는 방법**: 안드로이드에서 카카오톡의 사진이나 파일을 연 뒤 공유 버튼으로 "번뜩" 웹앱을 고릅니다. 웹앱을 홈 화면에 설치해야 공유 목록에 나타납니다. 메시지 글은 복사해서 웹앱이나 텔레그램 봇에 붙여 넣으면 됩니다.
- **카카오톡 채널 챗봇**: 카카오톡 채널을 만들고 카카오 i 오픈빌더에 챗봇을 등록해, 채널에 보낸 메시지를 이 서버로 받게 할 수 있습니다. 다만 서버에 공개 HTTPS 주소가 있어야 하고, 기본 응답 제한 시간이 5초라 AI 결과를 나중에 보내려면 콜백 기능 사용 신청과 승인이 필요합니다. 이 부분은 아직 구현하지 않았습니다.
